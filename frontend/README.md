# Velora Frontend

A soft, premium React frontend scaffold for the Velora file converter.

## Stack
- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- TanStack Query
- Axios
- React Hook Form + Zod
- Lucide React

## Run
```bash
npm install
npm run dev
```

## Notes
- API base URL points to `http://127.0.0.1:8000/api/v1`
- This scaffold already connects the image convert form and recent jobs dashboard
- Add more pages and API forms as backend routes grow
